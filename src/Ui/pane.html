Connect OpenRouter (about 3 minutes)

Describing nodes, 3D objects, textures, figures and trees use AI models, reached through OpenRouter and paid from your own OpenRouter credit. Everything else in Alien is free and works without it.
  1. Create an OpenRouter account

    Sign up with Google, GitHub or an email address. It's free to create.

  2. Add some credit

    Go to Settings › Credits and choose Add credits. US$5 goes a long way: a described node costs about US$0.002, a 3D object about US$0.02, and a texture or drawing about US$0.03.

  3. Create an API key

    Go to Settings › API Keys and choose Create API Key. Name it “Alien”. Setting a credit limit (say US$10) means a mistake can never overspend. Copy the key straight away: OpenRouter shows it only once. It starts with sk-or-v1-.

  4. Paste it here and link it

    Alien checks the key with OpenRouter, shows your credit, and saves it in settings.json on this computer only: never in .gh files, scripts or anything you share.

  5. Try it

    Press Done, type “divide a curve into 20 points” in the Describe box and press Enter. A new node appears and writes its own script in about 10 seconds. The menu at the top of this panel picks the model that writes nodes; Claude Haiku 5.5 is the tested, low-cost default.

Alien asks OpenRouter to use only providers that don't store or train on your prompts. Lost the key, or think someone else has it? Delete it on the API Keys page and make a new one.

Getting started

  • Place a node: click one in the library below (try vic_site_map with a Victorian address).
  • Describe a node: with nothing selected, describe a new one; with a node selected, describe a change to it.
  • Build on other nodes: drag a box around two or more nodes, then describe a node that uses them: it is wired to them for you.
  • Controls: sliders, switches and fields sit on the node. Only ▶ Generate buttons spend credit; sliders rework what was already made, for free.
  • Generated: the tab below keeps every 3D object, material and drawing the nodes made.

Troubleshooting

  • “No OpenRouter key”: link one above.
  • “Insufficient credits” or 402: add credit on OpenRouter (step 2), or raise the key's limit.
  • 401 / key not accepted: the key was mistyped, deleted or expired. Make a new one (step 3) and link it.
  • A node shows an error: select it and describe the fix (“the error says … fix it”), or open its code below.
  • Something else: keys, models, the script folder and the agent port are in settings.json.
